# SeleniumTestAutomation_Project

This is a project with Selenium where BDD Cucumber Framework is applied for the UI Test Automation, for Login Page and Contact Us Page of the Web Application https://www.webdriveruniversity.com/.

## Tech Stack
Automation Tool: Selenium
Framework: BDD Cucumber
Language: Java

## Getting Started
### Run Locally
1. Clone the project

```bash
  git clone https://github.com/IshaniShashikala/SeleniumTestAutomation_Project.git 
```

2. Open the project from IDE

3. Run maven commands

```bash
   mvn clean install
```
4. Run the project via Runner Class
